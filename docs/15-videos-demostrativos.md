# CeliaConnect – Videos Demostrativos

Esta sección contiene las demostraciones en video de las versiones Web y Android de CeliaConnect.

Los videos permiten visualizar el funcionamiento real de la plataforma y recorrer sus principales funcionalidades.

---

## Demo Web

La demostración Web presenta el funcionamiento de CeliaConnect desde un navegador, incluyendo la navegación por las principales secciones de la plataforma y las funcionalidades disponibles para los usuarios.

### Ver demostración

▶️ [CeliaConnect – Demo Web](https://youtu.be/xzG4Mn4hhDs)

---

## Demo Mobile

La demostración Mobile presenta la versión Android de CeliaConnect funcionando desde un dispositivo móvil.

La aplicación Android fue desarrollada utilizando Capacitor y Android Studio y permite acceder a las principales funcionalidades de la plataforma desde una aplicación instalada mediante APK.

### Ver demostración

▶️ [CeliaConnect – Demo Mobile](https://youtu.be/bWU5IfdM4-g)

## Plataformas disponibles

CeliaConnect cuenta actualmente con:

- Aplicación Web desplegada.
- Aplicación Android mediante APK.
- Backend mediante API REST.
- Base de datos MySQL.
- Manual de Usuario Web.
- Manual de Usuario Android.
- Videos demostrativos Web y Mobile.

Los videos complementan la documentación técnica y los manuales de usuario, permitiendo observar el funcionamiento de CeliaConnect en un entorno real.
