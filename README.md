# CeliaConnect

## Descripción

CeliaConnect es una plataforma Web y Mobile diseñada para centralizar información confiable para personas con celiaquía.

El objetivo del proyecto es facilitar el acceso a productos, restaurantes, locales, nutricionistas, recetas y promociones aptas para personas que siguen una alimentación libre de gluten, ofreciendo información actualizada en una única plataforma.

Entre sus principales funcionalidades se encuentran:

- 🥫 Consulta de productos Sin TACC.
- 🍽️ Búsqueda de restaurantes.
- 🛒 Consulta de locales especializados.
- 👩‍⚕️ Directorio de nutricionistas.
- 🍳 Recetas aptas para celíacos.
- 🎁 Promociones y descuentos.
- ⭐ Gestión de favoritos.
- 💬 Comentarios y valoraciones de la comunidad.

---

# Objetivo

Desarrollar una solución tecnológica que permita centralizar información confiable para la comunidad celíaca, mejorando la experiencia de búsqueda de productos y servicios mediante una plataforma intuitiva, moderna y multiplataforma.
