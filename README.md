# CeliaConnect

## Descripción

CeliaConnect es una plataforma web y móvil diseñada para centralizar información confiable para la comunidad celíaca.

La aplicación permitirá consultar:

- 🥫 Productos aptos sin TACC
- 🍽 Restaurantes
- 🛒 Tiendas
- 👩‍⚕️ Nutricionistas
- 🎁 Promociones
- ⭐ Favoritos
- 💬 Comentarios y valoraciones

## Objetivo

Desarrollar una solución tecnológica que facilite el acceso a información confiable y organizada para personas con celiaquía.

## Tecnologías

- React
- React Native + Expo
- Node.js
- SQL
- JWT
- Google Maps API
- Cloudinary
